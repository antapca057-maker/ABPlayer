## Установка

Скачайте `ABPlayer-vX.Y.apk` из раздела **[Releases](../../releases)** и установите на устройство.

Если при установке появляется предупреждение от системы — разрешите установку из неизвестных источников для того приложения, через которое вы открыли файл.

---

## Что нового в 1.1

* **Совместимость с Android 6–14:** библиотека получила доступ к аудиокнигам через системный выбор папки (SAF). Это заменяет прямой обход общего хранилища и работает без широких разрешений на доступ к файлам.
* **Сохранение доступа:** выбранная папка остаётся доступной после перезапуска приложения. После обновления её нужно выбрать заново; при выборе прежнего каталога сохраняются позиции, статусы книг, закладки и заметки.
* **Резервные копии через системный выбор файлов:** теперь можно выбрать место сохранения и файл для восстановления, а не только использовать фиксированный путь в `Download`.

## Основные возможности

* **Умная библиотека по папкам:** достаточно выбрать корневую папку — плеер автоматически объединит все аудиофайлы (`MP3`, `M4B`, `M4A`, `OGG`, `FLAC`, `WAV`, `AAC`, `OPUS`) внутри каждой подпапки в единую книгу, подхватит обложку (`cover.jpg` / `folder.jpg`) и разделит книги по статусам: **«Все»**, **«Новые»**, **«Начатые»**, **«Прочитанные»**.
* **Два ползунка навигации:**
  * *Верхний ползунок* — быстрая перемотка по всей книге с автоматическим переходом между главами и отображением общего прогресса (`Прослушано / Осталось`).
  * *Нижний ползунок* — точная навигация внутри текущего аудиофайла.
* **Переключение режимов ID3 (`Файл` / `UTF-8` / `Windows-1251`):** встроенная перекодировка решает проблему «кракозябр» в старых русских MP3-книгах одним нажатием.
* **Полноценный фоновый режим:** плеер работает как независимая служба (`Foreground Service` + `MediaSessionCompat`), не закрывается при смахивании приложения с экрана и выводит медиа-виджет с обложкой и кнопками управления (`-10с` / `Пауза` / `+10с`) в шторку уведомлений и на экран блокировки.
* **Управление с гарнитуры:** одиночное нажатие — Пауза/Старт, двойное — `+10 сек`, тройное — `-10 сек`.
* **Инструменты для комфортного чтения:**
  * Регулировка скорости воспроизведения (`0.8x` – `2.0x`) без искажения голоса.
  * Усиление тихой речи (`Boost`) и эквалайзер с профилями («Чёткая речь», «Глубокий бас»).
  * Таймер сна с продлением при встряхивании телефона.
  * Автоперемотка назад при возобновлении после паузы.
  * Закладки с заметками, блокнот персонажей для каждой книги, история перемещений и блокировка случайных нажатий.
* **Резервное копирование:** экспорт и импорт прогресса, закладок и заметок через системный выбор файла.
* **Полностью офлайн:** приложение не отправляет данные на серверы и не показывает рекламу.
